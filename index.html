파노체크 2.6

M5StickS3로 미니카 모터의 회전 주파수(파노)를 진동과 소리로 재는 프로그램입니다.

📵 아이폰으로는 USB 설치가 안 됩니다.
안드로이드폰(크롬)이나 컴퓨터(윈도우·맥의 크롬 또는 엣지)에서 이 주소를 열어 설치하세요.
2.0을 한 번 설치하면, 그 다음부터는 휴대폰 앱에서 블루투스로 업데이트됩니다.

📱 폰으로 설치 (안드로이드)

  1. 스틱을 USB-C 선으로 폰에 꽂습니다. (C-C 선, 또는 OTG 젠더)
  2. 아래 [폰으로 설치] → 목록에서 스틱(USB JTAG/serial 또는 ESP32-S3) 선택 → 허용.
  3. 약 1분 기다립니다. 끝날 때까지 선을 빼지 마세요.
안 될 때
  • 목록에 스틱이 없으면: 선을 뺐다 다시 꽂거나, 다른 USB-C 선(충전 전용 선은 안 됨)을 써 보세요.
  • "연결하지 못했습니다"가 나오면: 스틱을 빼고 다시 꽂은 뒤 한 번 더 누르세요.
  • 폰에 따라 USB 기기를 못 잡는 경우가 있습니다. 그럴 땐 컴퓨터로 설치하세요.
  • 활성화와 설정은 설치해도 지워지지 않습니다.

설치 방법

    
    
      
  1. M5StickS3를 USB-C 케이블로 PC에 연결합니다. (충전 전용 케이블은 안 됩니다)
    2. 
      
  2. 위의 CONNECT 버튼을 누르고, 목록에서 USB JTAG/serial debug unit (COM 번호)을 선택합니다.
    3. 
      
  3. INSTALL 파노체크 → INSTALL을 누르고 끝날 때까지 기다립니다.
    4. 
      
  4. 끝나면 스틱이 자동으로 다시 켜지고 파노체크 시작 화면이 나옵니다.
    5. 
      
  5. 활성화: 스틱 화면에 나오는 스틱 ID(예: 1DD6-25E0)를 제작자에게 보내고, 받은 활성화 링크를 안드로이드 크롬으로 연 뒤 스틱을 연결하면 끝납니다.
    6. 
    

  


  

    
목록에 스틱이 안 보일 때

    
    
      
  • 스틱 옆면 전원 버튼을 약 2초 누르고 있다가, 초록 LED가 깜빡이면 놓습니다 (다운로드 모드). 그 다음 다시 CONNECT를 누르세요.
    • 
      
  • 다른 USB 케이블이나 다른 USB 포트를 써 보세요.
    • 
      
  • Arduino IDE나 다른 시리얼 프로그램이 켜져 있으면 끄고 다시 시도하세요.
    • 
      
  • 설치가 끝났는데 화면이 그대로면 전원 버튼을 한 번 눌러 다시 켜세요.
    • 
    

  


  

    
사용법

    

      
앞 버튼 A 짧게모드 변경: VIB(진동) → MIC(소리) → VIB+MIC

      
앞 버튼 A 3초전원 끄기

      
옆 버튼 B 짧게탐색 범위: AUTO 250–700 Hz / LOW 40–260 Hz (저전압 길들이기) / WIDE 40–700 Hz

      
옆 버튼 B 1초화면 180도 회전

      
A + B 함께 3초블루투스 잠금 풀기 (휴대폰을 잃어버렸을 때)

    

    
MIC 모드: 진동이 느껴지면 잠시(기본 2.5초) 뒤 모터 소리에서 파노를 읽습니다.

    
VIB+MIC 모드: 진동을 인식하고 잠시 뒤 진동값과 소리값을 비교해 보여줍니다.

    
    
      
  • MATCH 두 값이 일치 (소리가 뚜렷할 때만) · MATCH? 값은 같지만 소리가 약함 · CLOSE 조금 다름 · VIB ONLY 소리가 안 잡힘
    • 
      
  • HOLD 모터가 멈춘 뒤 마지막 결과 유지
    • 
      
  • 큰 숫자 = 파노(Hz). 기준값(기본 550 Hz)을 넘으면 빨갛게 흔들립니다.
    • 
      
  • 아래 줄: V = 진동값, M = 소리값
    • 
    

    
대기 모드: 모터가 안 돌고 조작이 없으면 화면이 꺼집니다 (기본 30초). 버튼을 누르거나 모터가 돌면 바로 켜지며, 이때 첫 버튼은 화면만 켭니다.

    
자동 꺼짐: 배터리로 쓸 때 오래(기본 10분) 쓰지 않으면 꺼집니다. 꺼지기 10초 전에 화면 아래에 알려주고, USB에 꽂혀 있거나 휴대폰 앱이 연결돼 있으면 꺼지지 않습니다.

  


  

    
알아둘 점

    
    
      
  • 허락받은 스틱만 쓸 수 있습니다. 활성화 링크는 스틱마다 달라서 다른 스틱에는 쓸 수 없습니다.
    • 
      
  • 설치하면 스틱에 있던 기존 프로그램은 지워집니다.
    • 
      
  • PC 크롬/엣지, 또는 안드로이드폰 크롬(USB-C 선)으로 설치할 수 있습니다. 아이폰과 사파리에서는 설치되지 않습니다.
    • 
      
  • 앱에서 바꾼 설정은 스틱에 저장을 누르면 스틱에 들어가고, 스틱을 연결할 때도 자동으로 맞춰집니다.
    • 
      
  • 버전 2.6입니다. 2.0부터는 앱에서 블루투스로 스틱을 업데이트할 수 있어서, USB 설치는 이번 한 번이면 됩니다.

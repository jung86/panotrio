# 파노체크 (M5StickS3)

미니카 모터의 회전 주파수(**파노**, Hz)를 M5StickS3의 진동 센서와 마이크로 재는 프로그램입니다.
rpm = 파노 × 60 (예: 500 Hz = 30,000 rpm)

- **설치 페이지:** https://jung86.github.io/panotrio/ — PC 크롬/엣지로 열고 CONNECT → INSTALL
- **휴대폰 앱:** https://jung86.github.io/panotrio/app.html — 안드로이드 크롬 (블루투스)
- **현재 버전:** 2.4 (2.0부터 앱에서 블루투스로 펌웨어 업데이트: fw/latest.json, 서명 확인)

## 활성화

허락받은 스틱만 쓸 수 있습니다. 설치한 뒤 스틱 화면(또는 앱)에 나오는 **스틱 ID**를 제작자에게 보내면
**활성화 링크**를 받습니다. 링크를 안드로이드 크롬으로 열고 스틱을 연결하면 자동으로 활성화되며, 한 번이면 됩니다.

## 스틱 사용법

| 버튼 | 짧게 | 길게 |
|---|---|---|
| A (앞) | 모드: VIB → MIC → VIB+MIC | 3초: 전원 끄기 |
| B (옆) | 범위: AUTO 250–700 / LOW 40–260 / WIDE 40–700 Hz | 1초: 화면 180° 회전 |
| A + B | | 함께 3초: 블루투스 잠금 풀기 |

- **VIB:** 진동만으로 측정
- **MIC:** 진동을 인식하면 잠시(기본 2.5초) 뒤 소리로 측정
- **VIB+MIC:** 진동값과 소리값을 비교 — MATCH(소리가 뚜렷할 때만) / MATCH?(소리 약함) / CLOSE / VIB ONLY, 모터가 멈추면 HOLD
- 화면: 큰 숫자 = 파노(Hz), 아래 줄 V = 진동값, M = 소리값
- 기준값(기본 550 Hz)을 넘으면 숫자가 빨갛게 흔들림
- 휴대폰이 연결/해제되면 화면 아래에 BT CONNECTED / BT DISCONNECTED
- **대기 모드:** 모터가 안 돌고 조작이 없으면 화면 꺼짐(기본 30초). 첫 버튼은 화면만 켬
- **자동 꺼짐:** 배터리일 때 기본 10분 뒤 꺼짐(10초 전 경고). USB에 꽂혀 있거나 휴대폰 앱이 연결돼 있으면 꺼지지 않음

## 휴대폰 앱

시작 화면 → 메뉴에서 **파노측정** 또는 **설정**.

- **파노측정:** 큰 값, 진동/소리 값, 모드·범위 변경, 측정 초기화, 60초 그래프, 기록(모터별 분류·평균/최고/최저, 메모, CSV 저장)
- **설정 (스틱):** 화면 밝기, 진동 감도, 소리 감도, 측정 대기 시간, 빨간 숫자 기준, 대기 모드 진입 시간, 대기 모드 화면(끄기/어둡게), 자동 꺼짐, 대기 중 절전
  - 값을 바꾼 뒤 **스틱에 저장** → 스틱에 보내고 다시 읽어 확인
  - 스틱이 연결될 때 앱 설정과 다르면 앱 설정을 자동으로 스틱에 넣음
- **설정 (앱):** 연결 알림 진동/소리, 앱의 빨간 숫자 효과, 화면 꺼짐 방지
- 스틱 배터리 잔량 표시 (⚡ = USB 연결), 20% · 10%에서 알림
- 한 번 열어 두면 인터넷이 없어도 앱이 열림
- **블루투스 잠금:** 켜면 이 휴대폰만 모드·설정을 바꿀 수 있음 (스틱 A+B 3초로 해제)

## 모터클리닝 (DPS-150 전원공급기)

앱 메뉴의 **모터클리닝**에서 FNIRSI DPS-150을 USB로 제어해, 설정한 최소 ↔ 최대 전압(0~12 V)을 오르내리며 모터를 돌립니다. 전류 제한, 왕복 시간, 반복 횟수, 방향(정 / 역 / 번갈아)을 정할 수 있습니다.

- 연결: PD 충전기 → DPS-150 USB-C(전원) · 휴대폰 USB-C ↔ DPS-150 Micro USB(데이터) · 스틱은 블루투스
- 역방향: 스틱 Grove 포트(G9·G10)에 2채널 5 V 릴레이를 달아 극성을 바꿉니다 (펌웨어 1.9 이상).
  - 릴레이1: COM = 모터 A, NC = DPS +, NO = DPS −
  - 릴레이2: COM = 모터 B, NC = DPS −, NO = DPS +
  - IN1·IN2 = G9·G10, VCC = 5V, GND = GND. 두 릴레이가 같이 움직이고, 한쪽만 붙어도 단락되지 않는 배선입니다.
- 방향은 항상 출력을 끈 뒤 모터가 멈추고 나서 바뀝니다.
- 파노측정 화면의 **⚡ 전원공급기** 카드: 고정 전압·전류 제한·출력 ON/OFF·정/역. 출력이 켜져 있을 때 남긴 기록에는 전압·전류·방향이 함께 저장됩니다 (CSV에도 포함).
- **🩺 모터 컨디션** (파노측정): 출력이 켜져 있을 때 전류, 전압당 회전수(rpm/V), 회전 안정성, 진동·소리 차이, 정/역 차이를 보여 주고, 선택한 모터의 같은 전압 기록(2개 이상)과 비교해 0~100점으로 표시합니다. 점수는 기록과 CSV에도 남습니다.

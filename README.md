# 파노체크 (M5StickS3 · M5StickC Plus2)

미니카 모터의 회전 주파수(**파노**, Hz)를 M5StickS3(또는 M5StickC Plus2)의 진동 센서와 마이크로 재는 프로그램입니다.
rpm = 파노 × 60 (예: 500 Hz = 30,000 rpm)

- **설치 페이지:** https://jung86.github.io/panotrio/ — PC 크롬/엣지로 열고 CONNECT → INSTALL, 또는 안드로이드폰 크롬에서 스틱을 USB-C로 꽂고 [폰으로 설치]
- **휴대폰 앱:** https://jung86.github.io/panotrio/app.html — 안드로이드 크롬 (블루투스)
- **현재 버전:** 3.2 (2.0부터 앱에서 블루투스로 펌웨어 업데이트: fw/latest.json, Plus2는 fw/latest-plus2.json, 서명 확인)
  - 3.2: Plus2가 연결 직후·블루투스 업데이트 중 10~20초마다 다시 켜지던 것 고침(진동 센서 작업이 코어를 놓지 않아 작업 감시 타이머가 재시작), 업데이트 중엔 센서 읽기 멈춤, 켤 때 배터리 -1% 표시 고침
  - 3.1: 측정 시작 때 잠깐 엉뚱한 값이 나오던 것 고침(멈췄다 다른 속도로 돌릴 때, S3 400 Hz 근처), A 버튼을 누르고 있으면 전원 끄기까지 남은 시간 표시, 앱 [스틱 끄기], Plus2 대기 중 센서 읽기 15 ms
  - 3.0: 배터리 절전(대기 중 마이크 끄기·진동 센서 천천히 읽기), 앱이 연결돼 있어도 20분 안 쓰면 꺼짐, 앱 설정 「스틱 이름」이 블루투스 이름이 됨, Plus2 다시 켜짐 고침(CPU 160 MHz 고정)·배터리 % 표시
  - 2.9: 진동+마이크 모드에서 파노가 약 ±7% 안에서 흔들리면 다시 재지 않음

## 활성화

허락받은 스틱만 쓸 수 있습니다. 설치한 뒤 스틱 화면(또는 앱)에 나오는 **스틱 ID**를 제작자에게 보내면
**활성화 링크**를 받습니다. 링크를 안드로이드 크롬으로 열고 스틱을 연결하면 자동으로 활성화되며, 한 번이면 됩니다.

## 스틱 사용법

| 버튼 | 짧게 | 길게 |
|---|---|---|
| A (앞) | 모드: VIB → MIC → VIB+MIC | 3초: 전원 끄기 |
| B (옆) | 범위: AUTO 250–700 / LOW 40–260 / WIDE 40–700 Hz | 1초: 화면 180° 회전 |
| A + B | | 함께 3초: 블루투스 잠금 풀기 |

- **VIB:** 진동만으로 측정
- **MIC:** 진동을 인식하면 잠시(기본 2.5초) 뒤 소리로 측정
- **VIB+MIC:** 진동값과 소리값을 비교 — MATCH(소리가 뚜렷할 때만) / MATCH?(소리 약함) / CLOSE / VIB ONLY, 모터가 멈추면 HOLD
- 화면: 큰 숫자 = 파노(Hz), 아래 줄 V = 진동값, M = 소리값
- 기준값(기본 550 Hz)을 넘으면 숫자가 빨갛게 흔들림
- 휴대폰이 연결/해제되면 화면 아래에 BT CONNECTED / BT DISCONNECTED
- **대기 모드:** 모터가 안 돌고 조작이 없으면 화면 꺼짐(기본 30초). 첫 버튼은 화면만 켬
- **자동 꺼짐:** 배터리일 때 기본 10분 뒤 꺼짐(10초 전 경고). USB에 꽂혀 있거나 휴대폰 앱이 연결돼 있으면 꺼지지 않음

## 휴대폰 앱

홈 화면: 맨 위 **스틱 연결**, 큰 칸 **파노측정 · 모터클리닝 · 모터길들이기 · 설정**, 넓은 칸 **기록 · 비교**, 작은 칸 **설명서 · 업데이트 · 문의**. 자세한 사용법은 [설명서](https://jung86.github.io/panotrio/manual.html).

- **파노측정:** 큰 값, 진동/소리 값, 모드·범위 변경, 측정 초기화, 최근 60초 그래프, 기록(모터별 분류, 메모, CSV 저장). 기록은 5개씩 보이고 [이전 기록 더 보기]
- **모터 컨디션:** [청소 전] [청소 후] [그냥 측정] 버튼 하나로 연결 → 출력 켜기 → 3초 뒤 자동 측정 → 100점 만점 점수 → 출력 끄기. 결과를 음성·진동으로 알림, 청소 전·후 비교
- **기록 · 비교:** 모터 순위, 모터별 점수 그래프, 청소 효과, 결과 카드 공유(이미지)
- **설정 (스틱):** 화면 밝기, 진동 감도, 소리 감도, 측정 대기 시간(0~5초), 빨간 숫자 기준, 대기 모드 진입 시간, 자동 꺼짐, 대기 모드 시계
  - 값을 바꾼 뒤 **스틱에 저장** → 스틱에 보내고 다시 읽어 확인
  - 처음 연결한 스틱은 기본값으로 시작(스틱에도 저장), 그다음부터는 스틱에 저장된 값을 불러옴
- **설정 (앱):** 연결 알림 진동/소리, 측정 결과 음성·진동, 앱 열면 스틱 자동 연결, 화면 꺼짐 방지, 이상 경고, 릴레이 연결됨
- 스틱 배터리 잔량 표시, 20% · 10%에서 알림
- 한 번 열어 두면 인터넷이 없어도 앱이 열림. 새 버전은 앱을 열거나 돌아올 때 저절로 바뀜(작업 중엔 끝난 뒤)
- **블루투스 잠금:** 켜면 이 휴대폰만 모드·설정을 바꿀 수 있음 (스틱 A+B 3초로 해제)
- **문의 (오류·문의 신고):** 무슨 문제인지 적어 제작자에게 보내기, 같은 창의 [카톡으로 보내기]로 내용·버전·스틱 ID를 복사해 제작자 카톡으로. 앱 오류·연결 실패·업데이트 실패는 저절로 보고됨
- **보내는 정보:** 업데이트 관리와 오류 수정을 위해 앱·펌웨어 버전, 스틱 ID, 휴대폰 종류(오류 때는 연결 상태·최근 측정·화면 메시지도)를 제작자 서버로 보냄. 관리자만 볼 수 있음

## 모터클리닝 · 모터길들이기 (DPS-150 / DPS100 전원공급기)

앱의 **모터클리닝**에서 FNIRSI DPS-150(또는 같은 통신 방식으로 보이는 DPS100, 실물 미확인)을 USB로 제어해, 설정한 최소 ↔ 최대 전압(0~12 V)을 부드럽게 오르내리며 모터를 돌립니다. 전류 제한(기본 3.0 A), 왕복 시간, 반복 횟수, 방향(정 / 역 / 번갈아), 프리셋 저장. **모터길들이기**는 구간(전압·방향·시간·쿨링)을 최대 10개 정해 사이클로 반복하고, 사이클마다 파노를 재서 목표 파노에 닿으면 멈출 수 있습니다.

- 연결: PD 충전기 → DPS-150 USB-C(전원) · 휴대폰 USB-C ↔ DPS-150 Micro USB(데이터) · 스틱은 블루투스. 아이폰은 DPS 연결 불가
- 역방향: 스틱 Grove 포트(G9·G10)에 2채널 5 V 릴레이를 달아 극성을 바꿉니다 (펌웨어 2.2 이상, 앱 설정에서 **릴레이 연결됨**을 켜야 함).
  - 배선: Grove GND → GND, 5V → VCC, G9·G10 → IN1·IN2 (두 릴레이를 같이 구동), JD-VCC 점퍼 유지. 저레벨 트리거 보드면 앱에서 LOW 트리거 선택
  - 릴레이 접점: 릴레이1 COM = 모터 A, NC = DPS +, NO = DPS − / 릴레이2 COM = 모터 B, NC = DPS −, NO = DPS +
  - 2채널 SRD-05VDC-SL-C 보드(나사 위에서 1~6번, 1~3 K2, 4~6 K1): 1·6번 → DPS +, 3·4번 → DPS −, 2·5번(COM) → 모터. 어떤 상태에서도 단락되지 않습니다
  - 정방향일 땐 Grove 5V를 꺼서 릴레이에 전원이 가지 않음
- 방향은 항상 출력을 끈 뒤 모터가 멈추고 나서 바뀝니다.
- 실행 중 DPS 보호(OVP/OCP)를 필요한 만큼만 설정하고 끝나면 원래 값으로 되돌립니다.
- 파노측정 화면의 **전원공급기 · 정역** 카드: 고정 전압·전류 제한·출력 ON/OFF·정/역. 출력이 켜져 있을 때 남긴 기록에는 전압·전류·방향이 함께 저장됩니다 (CSV에도 포함).
- **모터 컨디션** 점수: 전류, 전압당 회전수(rpm/V), 파노 흔들림·변화, 전류 출렁임을 보고 같은 모터·전압의 이전 기록과 비교해 0~100점(85↑ 좋음, 65↑ 보통, 그 아래 점검 필요). 전원이 흔들리면 "전원 불안정"으로 점수를 내지 않습니다. 점수는 기록과 CSV에도 남습니다.

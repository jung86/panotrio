🤖 안드로이드

준비물: 안드로이드 휴대폰 · 크롬(Chrome) · 파노체크 스틱

크롬으로 파노체크 열기

  1. 크롬으로 열기 위 [크롬으로 파노체크 열기]를 누르세요. 주소: jung86.github.io/panotrio/app.html
    ⚠ 삼성 인터넷, 카카오톡·네이버 앱 안의 브라우저에서는 스틱이 연결되지 않습니다. 꼭 크롬으로 여세요. (잘못 열면 화면 위에 [크롬으로 열기] 버튼이 뜹니다)
  2. 홈 화면에 설치 앱 첫 화면의 [📲 홈 화면에 앱 설치], 또는 크롬 메뉴 ⋮ → 홈 화면에 추가. 다음부터 아이콘으로 바로 열립니다.
  3. 블루투스 · 위치 켜기 휴대폰의 블루투스와 위치(GPS)를 둘 다 켭니다. 안드로이드는 위치가 꺼져 있으면 스틱을 못 찾습니다.
  4. 스틱 연결 스틱을 켜고 [스틱 연결 (블루투스)] → 목록에서 파노체크-XXXXXXXX 선택 → 연결.
    목록에 안 나오면: 스틱이 다른 휴대폰에 연결돼 있지 않은지 확인하고, 스틱을 껐다 켜 보세요. 스틱은 휴대폰 한 대하고만 연결됩니다.
  5. 처음 한 번: 활성화 새 스틱은 잠겨 있습니다. 앱의 [📨 활성화 요청 보내기]를 눌러 제작자에게 카톡으로 보내고, 답장으로 온 활성화 링크를 누른 뒤 [스틱 연결]만 하면 끝납니다.
  6. 측정 메뉴 파노측정 → 스틱을 모터에 대거나(진동) 가까이 둡니다(소리). 진동+소리 모드에서 두 값이 맞으면 MATCH로 표시됩니다.
  7. (선택) 전원공급기 DPS-150 / DPS100 휴대폰 USB-C ↔ DPS-150 Micro USB(데이터선)(DPS100은 PC COMM 단자)을 연결하고, 파노측정의 ⚡ 전원공급기 [연결] → 목록에서 선택(첫 목록에 없으면 닫기 → 전체 목록). 한 번 허락하면 다음부터는 저절로 연결됩니다. 전압·전류 설정, 정/역(릴레이), 🩺 모터 컨디션, 모터클리닝 자동 운전을 쓸 수 있습니다.
    DPS-150 전원은 PD 충전기(65W 이상, 20V 지원)로 넣어야 12V까지 나옵니다.

🍎 아이폰

아이폰의 사파리·크롬은 블루투스 웹앱을 지원하지 않아서, 무료 앱 Bluefy(블루투스 지원 브라우저) 안에서 엽니다.

Bluefy 받기 (앱스토어) Bluefy로 파노체크 열기
  1. Bluefy 설치 위 [Bluefy 받기] → 앱스토어에서 무료로 설치합니다.
  2. Bluefy에서 파노체크 열기 위 [Bluefy로 파노체크 열기]를 누르면 Bluefy 안에서 바로 열립니다. 안 열리면 [파노체크 주소 복사] 후 Bluefy 주소창에 붙여넣으세요. 주소: jung86.github.io/panotrio/app.html
    Bluefy의 즐겨찾기(☆)에 넣어 두면 다음부터 바로 열립니다.
  3. 블루투스 허용 처음에 Bluefy가 블루투스 사용을 물어보면 허용을 누릅니다.
  4. 스틱 연결 [스틱 연결 (블루투스)] → 목록에서 파노체크-XXXXXXXX 선택.
  5. 처음 한 번: 활성화 [📨 활성화 요청 보내기]로 제작자에게 보내고, 답장으로 온 활성화 링크를 받습니다.
    카톡의 활성화 링크를 누르면 자동으로 Bluefy로 넘어갑니다 ("Bluefy에서 열까요?"가 나오면 열기). 안 넘어가면 링크를 길게 눌러 복사하고, Bluefy의 파노체크에서 [📋 복사한 활성화 링크 붙여넣기]를 누르세요.
  6. 측정 안드로이드와 같습니다. 메뉴 파노측정에서 진동·소리로 잽니다.

아이폰에서 안 되는 것: 전원공급기(DPS-150 / DPS100) 연결, 모터클리닝 (아이폰이 웹의 USB 연결을 막습니다)

💻 스틱 펌웨어 설치·업데이트 (PC · 안드로이드폰)

스틱을 USB-C로 PC에 꽂고, PC의 크롬 또는 엣지로 설치 페이지를 엽니다. 활성화는 업데이트해도 유지됩니다.

📱 안드로이드폰: 스틱을 USB-C 선(C-C 또는 OTG 젠더)으로 폰에 꽂고, 폰 크롬으로 설치 페이지를 열어 [폰으로 설치] → 스틱 선택 → 허용. 폰에 따라 안 될 수 있으며, 그럴 땐 PC로 설치하세요. 아이폰은 안 됩니다.

자주 묻는 문제

스틱이 목록에 안 나와요
  • 블루투스와 위치(GPS)가 켜져 있는지 확인하세요.
  • 다른 휴대폰에 이미 연결돼 있으면 안 보입니다. 그 휴대폰의 앱을 닫거나 스틱을 껐다 켜세요.
  • 삼성 인터넷·카톡 브라우저가 아니라 크롬(아이폰은 Bluefy)인지 확인하세요.
"활성화가 필요한 스틱입니다"가 떠요

앱의 [📨 활성화 요청 보내기]로 제작자에게 스틱 ID를 보내고, 받은 링크를 크롬(아이폰은 Bluefy)으로 연 뒤 스틱을 연결하세요.

새 기능이 안 보여요

앱을 완전히 닫았다가 다시 여세요. 설정 → 정보 맨 아래에서 앱 버전을 확인할 수 있습니다.

DPS-150 / DPS100이 목록에 안 나와요
  • 충전 전용 선이 아닌 데이터선인지 확인하세요.
  • DPS-150 전원이 켜져 있어야 합니다.
  • 선을 뽑았다 다시 꽂고 [연결]을 누르세요.
